## Introduction

"Odin Recipes" is a simple recipe site built as part of the Foundations course on The Odin Project. It shows the homepage of the site with three links to pages showing recipes. Each recipe page has a list of ingredients, instructions for cooking, images and further information.

## Skills Demonstrated

By completing this project, I learned how to:

- Create web pages using HTML
- Use headings, paragraphs, and lists
- Add links and images
- Create multiple web pages
- Use tables and forms
- Add videos and other media
- Use semantic HTML tags
- Improve website accessibility
- Use Git and GitHub to manage a project
  
## Reflection

Through this project I have gained hands on experience of creating a multipage website. This has taught me the importance of having clean and accessible HTML code. This has increased my knowledge of basic web development concepts and will help me create more complex HTML and CSS projects.
